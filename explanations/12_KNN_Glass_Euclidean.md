# Program 12: KNN Euclidean on Glass Dataset

**Logic / Algorithm:** This is identical to the core concepts of Program 7, but focuses exclusively on the **Euclidean Distance** metric.
Euclidean distance is the "ordinary" straight-line distance between two points in Euclidean space. 

**Mathematical formula:** 
$d(p, q) = \sqrt{(p_1 - q_1)^2 + (p_2 - q_2)^2 ...}$

**Real-World Example:** If you are trying to find the closest coffee shop to your house by flying a drone in a straight line over the buildings, you are using Euclidean distance. In machine learning, it finds the "closest" data point in a straight line across all its feature dimensions.
