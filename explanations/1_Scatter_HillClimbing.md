# Program 1: Scatter Plots & Hill Climbing

## 1(a): Scatter Plot
**What it does:** Visualizes data points on a 2D Cartesian plane using two features (e.g., Sepal Length vs. Sepal Width from the Iris dataset).
**What to look for:** Look for clusters, trends, or correlations. If points of the same color (class) bunch together, it means those two features are good at separating the classes!
**Real-World Example:** Plotting *House Price* (Y-axis) vs *Square Footage* (X-axis). A scatter plot instantly shows if larger houses generally cost more.

## 1(b): Hill Climbing Algorithm
**Logic / Algorithm:** It is a mathematical optimization technique belonging to the family of local search. It starts with a random solution and iteratively makes small changes, keeping the change only if it improves the objective function. It stops when it reaches a "peak" where no neighbors are higher.
**Real-World Example:** Tuning a radio dial. You turn it slightly left or right; if the static gets quieter (better signal), you keep turning in that direction until the signal is perfectly clear. 
**Exam Tip:** Mention the "Local Maximum" problem—Hill climbing can get stuck on a small hill and miss the tallest mountain (Global Maximum).
